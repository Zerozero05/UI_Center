# Windows 规范与组件浏览器

浏览器适合在优化界面前快速查原则、筛选组件和复制采用说明。它使用 Python 标准库 Tkinter；Windows 运行包自带 Python/Tcl/Tk，无需安装开发环境。完整源代码和维护资料以同版本 GitHub 标签为准。

## 下载与启动

从 [GitHub Releases](https://github.com/Zerozero05/UI_Center/releases) 下载 Windows x64 运行包，用 `SHA256SUMS` 对照文件哈希。优先使用便携 ZIP：解压后双击 `UI_Center.exe`，保留整个 `_internal` 目录，不从压缩包内直接启动。

单文件 EXE 使用同一功能和内容，启动时将必要运行库释放到临时目录，正常退出后由打包运行时处理。它减少可见文件数量，不代表运行时没有额外磁盘占用。程序无需管理员权限，也不安装系统服务。

## 查阅与复用

1. 按通用、Tkinter 或 Android 选择适用平台；通过标题、场景和关键词搜索。
2. 阅读条目的适用范围和状态。规范条目不等于已实现的控件；Android 设备未实测的标记不能视为已验证。
3. 查看说明和实际用法。桌面预览使用内存模拟任务，不处理你的文件。
4. 使用“复制用法/采用说明”取得条目、所用提交、GitHub 地址和许可提醒，再交给目标项目的开发任务。
5. 在目标项目验证自己的业务、配置、长文本、键盘、主题与任务生命周期；按 [源码复制与更新](consumption.md) 记录本地调整。

浏览器附带规范和使用说明的只读快照，断网仍可查阅和预览；打开 GitHub 来源或发行页需要网络。源码链接固定到构建提交，不会默默切到更新后的 main。完整源码无需放在日常运行目录中。

## 界面与数据

明暗主题只作用于本程序。搜索、选中内容和已打开预览中的有效输入/任务状态应在切换主题后保留。Ctrl+F 定位搜索，Esc 清除搜索；Tab/Shift+Tab 移动焦点，说明和用法可选择复制。

首版为只读浏览器，不包含账号登录、在线 AI 调用、笔记编辑、收藏同步或自动更新。不会修改目标应用或把数据上传到 GitHub。主题等临时状态在退出后不保存，普通启动不生成用户配置。

## 更新与恢复

需要升级时手动打开 GitHub 发行页，先查看变更与未测范围，再下载完整新包。便携版应整包替换，不混合不同版本的 EXE 和 `_internal`。此前已复制到应用的组件不会随浏览器自动更新，仍需按来源提交比较合并。

程序“来源/关于”内容提供版本、固定提交、许可及源码入口；源码包保留构建脚本和锁定的打包工具。实际下载大小、解压大小、检查结果和是否已签名以该次发行说明为准。SHA-256 用于核对文件一致性，不代替开发者数字签名。

## 后续建议

- 日常只保留便携版，单文件 EXE 作为另一种分发选择保存在 GitHub，避免本机重复保存两套运行时。
- 界面优化任务先粘贴“条目 + 固定提交 + 目标项目约束”，比笼统要求“参考最新 UI”更容易复核与升级。
- 新组件先进入场景示例，并覆盖正常、禁用、忙碌、成功、取消和错误；实际用于两个独立项目后再考虑组件包。
- 若以后确实需要 Web 消费者，再引入 Web 实现或 Storybook；当前浏览器继续保持原生、小依赖和离线可用。
- 公开源码、必要测试和脱敏验证摘要；私钥、本机绝对路径和原始私人诊断记录不进入公共附件。
