# v1.3.0

重做UI_Center工作台布局，并优化全部18项Tkinter组件与3个旧预览。采用左侧检索和分类导航、顶部复用操作及组件展示/参数检查器，窄窗口自动上下排列。外观和筛选按需展开。

- 统一四主题、圆角原生控件、状态标记和键盘焦点。保留中文用法、当前参数示例及既有组件API。
- 加载采用双圆点Spinner、真实进度和圆角骨架/扫光。弹层、标签页、折叠面板、分段选择、提示及空状态同步改进。
- 借鉴Impeccable、awesome-design-md和Galaxy的固定文件。Spinner为Galaxy样式的原生改编，随源码及运行包保留完整MIT版权。其余按具体方法自行实现。无新增第三方运行依赖。

Windows11 x64，无需Python，EXE未代码签名。单文件EXE适合本地只保留最少文件。便携ZIP需完整解压并保留_internal。配置在实际EXE旁data目录，私人资料独立保留。
