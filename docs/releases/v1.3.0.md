# v1.3.0

根据三个设计参考仓库，优化工作台和全部18个现有Tk组件及3个旧预览。公开发布和日常替换尚未进行，具体候选附件准备完成后单独确认。

## 改动

- 重做左侧搜索/分类/筛选、顶部复用操作及“组件展示＋参数检查器”布局；宽窗口左右排列，窄窗口上下排列。统一四主题、原生圆角按钮、页签与状态，保留中文参数。
- 加载增加完成色、细轨道、圆头圆环与圆角进度条，骨架/扫光采用圆角裁剪；加载按钮增加独立忙碌外观，区域加载采用居中提示卡；区域加载层显示已知真实进度时停止装饰计时。
- 弹层标题与操作分区、工具提示换行和间隙更明确；标签页选中下划线、分段圆角组和独立折叠面板；行内/轻通知增加矢量语义标记，空状态以原生线条图形分层。
- 新增DESIGN.md、三仓库固定参考和18项映射，可在离线内容中查阅。源码入口包括绘图辅助模块，无新增第三方运行依赖。

## 兼容性

支持目标为Windows11 x64，无需预装Python；EXE未代码签名。保留公开组件API、18条目ID、当前参数代码、三字段偏好、4主题/3字号、减少动画及原有目录。两端继续使用同一JSON，Android源码不迁移框架；Android设备运行未测。

复制整个组件目录与tokens。新增divider/accent_soft装饰角色不替代原语义；旧JSON可读取并在内存补齐文件之外的默认值，不回写文件。主题和参数更新不应清空输入、选择、阅读位置或任务进度。

## 附件与验证

计划提供便携ZIP、单文件EXE、完整源码ZIP和SHA256SUMS，文件名中的版本为v1.3.0；运行包不包含开发环境或私人数据。实际提交、构建、运行验证与未测范围见[验证记录](../../VALIDATION.md#v130-设计改进候选)，不能用旧版通过项替代本候选证据。

当前公开最新版仍为v1.2.3，所有旧发行保留。日常替换仅在具体确认后进行，保留data/dev/UI_Center_Private；本轮未创建备份或清理文件。
