# v1.2.3

本版统一中文参数和现有组件的界面呈现。二选一使用相邻文字按钮，减少含义不清的选中标记；参数、顶部和工具操作按窗口宽度重排，短提示紧凑显示，滚动条按需出现。

## 改动与使用

- 长文本、可用/禁用、效果开启/关闭、布局、抽屉方向及背景交互采用文字分段；其他预览枚举使用中文下拉。源码继续使用原布尔/英文API值。
- 每个预览保留一个重置；顶部空间不足自动换行，复制示例为主要操作。暖纸/灰绿/浅色/深色与100/125/150%字号保持；减少动画时保留原效果选择和静态原因。
- 行内提示短消息按内容收缩，最多四行，长内容可滚动选择复制；标签页、分段、折叠及弹层的边线、间距和焦点更一致。
- 预览、条目列表、正文与源码按溢出显示滚动条，代码仍支持横向查阅。Windows工作台优先使用本机微软雅黑UI，不捆绑新字体或框架。

## 兼容与交付

组件构造器、方法、回调、条目ID、三字段外观偏好和单总目录保持；参数适配层只属于工作台，不是消费源码依赖。无新增运行依赖，不改变Android共享参数或设备验收边界。

支持目标Windows11 x64，EXE未代码签名。候选将提供便携ZIP、单文件EXE、完整源码ZIP及SHA256SUMS；升级只替换同版本EXE/_internal，保留dev/data/UI_Center_Private与旧发行。当前尚未取得本版具体发布确认，实际检查见[候选验证记录](../../VALIDATION.md#v123-参数与界面候选)。
