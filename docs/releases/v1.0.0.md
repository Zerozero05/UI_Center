个人 UI 规范与源码复用中心的首个正式源码版，优先服务 Windows 11 上的 Tkinter/ttk 桌面程序。

## 内容

- UI 设计规范、六类交互模式、案例与按平台和场景分类的索引。
- 单一 JSON 设计参数，及 Tkinter/ttk、Java Android Views 的主题、操作区、任务进度与结果反馈源码。
- 使用虚构数据的独立示例、源码复制/升级说明、固定上游来源及许可记录。

## 使用与兼容性

下载 `UI_Center_v1.0.0_Source.zip` 并解压，先阅读 README、AGENTS 和 VALIDATION。桌面示例需要含 Tcl/Tk 的 Python 3.10+，从解压目录运行 `python examples/tkinter/demo.py`。Android 示例的构建要求和后续设备验证步骤见其 README。

这是首次源码版，没有既有版本迁移步骤。复制到应用时保留来源提交、版权和许可；业务、文件处理与应用配置由原应用管理。以后更新先比较本地修改，回退可重新采用本标签源码。自有与改编内容采用 AGPL-3.0-only，第三方内容按来源说明保留许可。

## 验证与限制

Windows 11 桌面已验证明暗主题、禁用与忙碌状态、键盘焦点、开始/取消/完成/错误和独立源码消费。桌面11项控件测试、Android主包/测试包构建与lint、16项宿主状态检查、APK参数一致性检查均已通过；正式标签流程要求这些检查再次通过后才发布。

Android 源码与构建结果保留，设备运行验收按已确认范围后延。未验证冻结EXE、全部DPI、多显示器、系统原生文件对话框及非Windows桌面环境。Android lint 的5项警告与未测范围见 VALIDATION；本次不提供 Android APK 或桌面安装程序。
