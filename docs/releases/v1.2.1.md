# v1.2.1

本版修正本机目录分散与固定配置位置，并在帮助中明确实际保存位置。已按本次具体确认[正式发布](https://github.com/Zerozero05/UI_Center/releases/tag/v1.2.1)；固定提交4612fa8、批准候选原运行字节、101源码文件及四公开附件已独立核验，最终大小/哈希和实际范围见[公开验证记录](../../VALIDATION.md#v121-公开附件核验)。

## 改动与位置规则

- 本机项目统一到一个UI_Center总目录：日常UI_Center.exe/_internal原位，完整维护仓库放dev，日常设置放data，UI_Center_Private原位保留。缓存、备份、候选和工作记录在dev/work。
- 便携与单文件EXE均在实际可执行文件旁的data/preferences.json保存主题、字号、动画；不再写死D盘某个同级目录，也不以单文件临时解包位置保存数据。源码调试使用仓库work/data，显式注入路径继续优先。
- 使用帮助显示可复制的程序目录和设置文件路径，并提供打开目录按钮；目录尚未存在或打开失败时提示，不因查看帮助创建文件夹。
- 原组件、预览、主题/字号、快捷键、复制、三字段配置及源码消费接口保留。本次不加入收藏、离线导出、新组件或依赖。

## 从v1.2.0迁移

先关闭旧程序，保留旧包和设置；将旧UI_Center_Dev整个移入总目录dev、旧UI_Center_Data整个移入data，再使用同一候选/发行的新版EXE和完整_internal。已有dev/data目标时不要直接覆盖或混合。

旧v1.2.0EXE仍有旧路径行为，不能只搬配置后继续运行它。新版不自动扫描或迁移旧绝对路径，既有preferences.json由迁移流程原样保留；缺少设置时使用默认外观，读取/写入错误提示继续有效。

升级只更换EXE与_internal，保留dev/data/UI_Center_Private。目录迁移不授权删除源码、缓存、日志或旧版；旧v1.2.0及以前标签和附件保持不变。

## 附件与验证边界

| 附件 | 用途 |
| --- | --- |
| UI_Center_v1.2.1_Windows_x64_Portable.zip | 完整解压后运行UI_Center.exe，保留_internal；推荐日常使用 |

支持目标仍为Windows11 x64。源码路径测试、帮助真实控件、两种实际冻结包和本机迁移分别检查，记录实际通过及未测范围见[验证记录](../../VALIDATION.md#v121-目录与位置说明候选)。Android仅回归既有构建/状态，设备运行后延；其他操作系统、所有DPI/多显示器/辅助技术没有全面实测。

没有新增外部借鉴、运行依赖或组件许可变化。来源和AGPL-3.0-only及实际运行库声明继续保留。正式发布须在具体版本/附件/验证材料准备好后取得本次明确确认，标题仅v1.2.1。
