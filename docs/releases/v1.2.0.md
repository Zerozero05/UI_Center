# v1.2.0

本文件记录v1.2.0改动与验收边界。是否已正式发行以[发行页](https://github.com/Zerozero05/UI_Center/releases)为准；具体源码提交、候选run、附件大小及SHA-256由本次准备脚本写入发行正文和校验文件，本说明不代替实际包验证或发布确认。

## 改动

工作台以组件为入口组织“组件库”“设计规范”“资料与来源”，支持中文名称、英文别名与场景搜索。组件分别呈现“实时预览”“中文用法”“示例与源码”；规范条目使用单一原文视图，减少重复说明。

新增18个使用 Python 标准库 Tk/ttk/Canvas 自行实现的组件：

| 组 | 组件 |
| --- | --- |
| 加载（7） | Spinner、ProgressBar、CircularProgress、Skeleton、Shimmer、LoadingButton、PageLoader |
| 弹层（5） | Dialog、ConfirmDialog、Drawer、Popover、Tooltip |
| 导航（3） | Tabs、Accordion、SegmentedControl |
| 反馈（3） | InlineAlert、Toast、EmptyState |

每项提供独立内嵌预览、可选独立窗口、中文用途/边界/API、最小用法和源码入口。“复制示例”使用当前内嵌参数；“AI 说明”附带来源与适用边界；“重置此组件”恢复默认参数。原主题、ActionBar、TaskPanel 和既有规范/Android 条目继续保留各自入口与实际用法。

新增暖纸 `warm`、灰绿 `sage`，保留浅色 `light`、深色 `dark`；工作台默认暖纸主题、12pt正文，提供100% / 125% / 150%字号。切换外观保留当前有效输入、进度和选择；切换组件条目会释放上一项预览，返回后重新创建默认实例。

动画支持跟随系统、正常、减少。减少动画保留静态状态与真实百分比；隐藏预览暂停装饰计时器，销毁后释放回调。可复用组件只呈现状态与发出调用者回调；模拟任务只存在于演示层，LoadingButton 保留真实 ttk.Button，PageLoader 仅覆盖局部 stage。

## 兼容与数据

- 原 `apply_theme`、ActionBar、TaskPanel API 保留；`apply_theme` 默认倍率1.0继续使用既有基础字号，12pt是工作台在100%下的显示选择。
- 复制消费时仍需要完整 `ui_center` 包和 `tokens/design-tokens.json`，显式传参数路径；仅复制示例或单个类文件不能替代依赖。见[复制说明](../consumption.md)。
- 仅主题 `theme`、字号 `font_scale`、动画 `motion` 保存到 `D:\03_github_projects\UI_Center_Data\preferences.json`；搜索、预览参数、输入、进度和结果不持久保存。偏好读取/写入失败有界面提示，当前会话仍可使用。
- 当前默认运行目录保持 `D:\03_github_projects\UI_Center`，仅替换同一发行的 `UI_Center.exe` 与 `_internal`；必须保留已有 `D:\03_github_projects\UI_Center\UI_Center_Private`，也保留外置偏好。此说明不授权清理任何目录。
- 新18项仅为 Tkinter 实现；Web/Android 内容为规范映射，既有 Android 示例仍保留，未新增相应平台的18个控件或扩大设备验证范围。
- 没有新增第三方源码、资源或运行依赖，既有方法参考、源码改编署名和 AGPL-3.0-only 许可继续有效。见[来源记录](../../references/sources.md)与[第三方声明](../../THIRD_PARTY_NOTICES.md)。

## 验收与交付

源码阶段的实际结果和限制见[验证记录](../../VALIDATION.md#v120-候选源码与验收范围)。最终发行门禁要求同一候选提交的源码测试、Android构建、两个Windows冻结包、包内资源/许可/源码身份以及实际运行检查成功；发布只使用已经审阅并固定SHA-256的候选附件。

| 附件 | 用途 |
| --- | --- |
| `UI_Center_v1.2.0_Windows_x64_Portable.zip` | 完整解压后运行UI_Center.exe，保留同目录_internal；推荐日常使用 |
| `UI_Center_v1.2.0_Windows_x64.exe` | 单文件运行，启动时释放必需运行资源；无需安装Python |
| `UI_Center_v1.2.0_Source.zip` | 固定提交的完整源码、文档、构建和测试，用于复用 |
| `SHA256SUMS` | 上述三个附件的精确校验值 |

兼容目标为Windows 11 x64。程序不依赖新安装的UI框架、外部字体或网页引擎；实际运行库与许可随包检查。Android设备、所有显示缩放、所有辅助技术和其他操作系统没有全面实测。源码、CI、冻结运行和人工窗口检查分别报告；未经本次具体确认不创建标签或正式发行，旧版本保留。
