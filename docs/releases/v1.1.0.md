# v1.1.0

新增 Windows 11 x64 规范与组件浏览器，支持离线查阅、平台/场景检索、复制用法与采用说明，以及真实 Tkinter 预览。完整源码仍用于在其他应用中复用；原 PDF 应用和 Android 组件接口保持独立。

## 附件

- `UI_Center_v1.1.0_Windows_x64_Portable.zip`：推荐日常使用，完整解压后运行 `UI_Center.exe`，保留 `_internal`。
- `UI_Center_v1.1.0_Windows_x64.exe`：单文件运行版，启动时释放临时运行库。
- `UI_Center_v1.1.0_Source.zip`：对应完整源码、规范、测试、构建脚本和许可。
- `SHA256SUMS`：上述附件的 SHA-256。

两种 Windows 运行包无需自行安装 Python。首版支持 Windows 11 x64；其他 Windows 版本、ARM64 原生、macOS/Linux 冻结包未验证。没有 APK、安装器、自动更新或管理员权限要求。

## 行为与兼容性

浏览器使用统一设计参数和既有 Tkinter 组件；规范、实际可运行组件、Android 源码参考分别标明。浏览内容随构建固定到源码提交，GitHub 链接不漂移到 main。现有组件源码复制方式继续可用。

v1.0.0 只有源码示例，本版新增独立应用，无需迁移用户配置。日常运行不写用户配置；退出后临时主题和搜索状态不持久化。升级便携版时整包替换，不混用不同版本的 EXE 和运行库。

## 验证与限制

实际源码、冻结包和公开附件检查结果随该次发布流程列出，详细范围见仓库 VALIDATION。Android 源码和构建结果继续保留，设备启动、触控、旋转、输入法和视觉验收按已确认范围后延。

单文件形式不代表零临时文件；程序未承诺全部 DPI、多显示器或其他平台均通过。没有附带开发者代码签名证书，校验值用于文件一致性验证。

## 来源与许可

自有与已有改编源码继续使用 AGPL-3.0-only，同版本完整源码与运行附件位于同一发行入口。运行包内保留实际分发的 Python、Tcl/Tk 及所含其他二进制的版权和许可，可在程序来源/许可入口查阅。PyInstaller 是构建工具，其分发例外不替代这些运行依赖的许可。
