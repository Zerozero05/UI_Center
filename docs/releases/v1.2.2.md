# v1.2.2

本版改善骨架与扫光的辨识、中文效果选项，以及分类内搜索的筛选和空结果恢复。骨架使用平滑脉动，扫光在稳定底色上仅沿占位形状移动；启用减少动画时，两者保留静态占位并明确说明原因。

## 改动与使用

- 骨架屏显示“脉动效果：开启／关闭”，扫光骨架显示“扫光效果：开启／关闭”，替换含义不清的×选中标记。布局显示列表／卡片，生成代码仍映射原英文参数与布尔值。
- 全局减少动画优先，局部选择保留且禁用；恢复正常动画仅恢复仍运行的预览。状态说明区分效果运行、关闭、停止与减少动画降级，内嵌和独立预览沿用同一实现。
- 平台按内容分类、场景按分类＋平台提供有效选项，不随关键词跳动；保留有效选择，仅重置失效项。搜索仍只匹配当前分类的名称、摘要、别名、场景与条目ID。
- “清空关键词”仅清文字；空结果展示当前条件，提供“显示本类全部”，清关键词、平台与场景并保留分类。空结果隐藏规范标签和无用条目动作，恢复结果后正常显示。

## 兼容性与升级

保持原组件类、参数、方法、稳定条目ID及3字段外观设置。仅界面联动会调整已不适用的筛选；纯筛选函数保持原精确语义。没有新增依赖、设置字段、组件类别、收藏、全文搜索或跨分类搜索。

支持目标仍为Windows11 x64，EXE未代码签名，无需另装Python。升级时退出旧程序，成对更新EXE及完整_internal，保留同总目录的dev/data/UI_Center_Private。现有版本、标签及历史附件保留，不清空目录；本机旧运行包备份放dev/work。
